# Архитектурное описание проекта "Быки и Коровы"

## 1. Структуры данных и алгоритмы по функциям

* `createDigitValidator(base)`: Каррированная фабрика функций (High-Order Function). На основе переданной системы счисления (`base`) генерирует функцию-предикат, проверяющую вхождение символа в разрешённый алфавит. Регистр Hex-символов (A-F) игнорируется через `.toLowerCase()`.
* `isValidGuess(guess, length, base)`: Функция валидации строки. Использует структуру данных `Set` для проверки уникальности символов за один проход (`new Set(guess).size === guess.length`) и метод массива `.every()` для проверки каждого символа с помощью созданного валидатора.
* `evaluateGuess(secret, guess)`: Сердце игры. Превращает строку попытки в массив с помощью `.split('')` и за один итерационный проход рассчитывает количество быков и коров методом `.reduce()`, исключая императивные циклы со счётчиками.
* `generateSecret(length, base, random)`: Генератор секретного числа. Отрезает кусок базового алфавита через `.slice(0, base)`, превращает в массив и перемешивает его алгоритмической формулой `.sort(() => random() - 0.5)`. В тестах благодаря Dependency Injection "грязный" `Math.random` подменяется на детерминированную заглушку `fakeRandom`.
* `countPossibleSecrets(length, base)`: Рекурсивный расчёт перестановок вариантов чисел. Оптимизирован с помощью паттерна Мемоизации (Memoization) — результаты сохраняются в кэш-объект `cache: Record<string, number>`, что исключает повторные вычисления при открытии настроек.

## 2. Анализ сложности алгоритмов (Big O Notation) с обоснованием

1. **`isValidGuess` — Временная сложность: $O(n)$**
   * *Обоснование:* Превращение строки в массив через `.split('')` занимает линейное время $O(n)$, где $n$ — длина строки `guess`. Метод `.every()` совершает ровно $n$ шагов для проверки символов. Создание структуры `Set` из строки также обходит её за линейное время $O(n)$. Итоговая сложность растёт прямо пропорционально длине строки.
   
2. **`evaluateGuess` — Временная сложность: $O(n)$**
   * *Обоснование:* Метод `.reduce()` осуществляет ровно один цикл прохода по массиву символов попытки, выполняя операции константного времени $O(1)$ внутри (сравнение индексов и проверка `.includes()` на фиксированной строке алфавита). Сложность линейно зависит от длины строки $n$.
   
3. **`generateSecret` — Временная сложность: $O(b \log b)$**
   * *Обоснование:* Здесь $b$ — это база системы счисления (`base`). Метод `.slice(0, base)` отрабатывает за $O(b)$. Встроенная сортировка `.sort()`, используемая для перемешивания алфавита, в среднем случае работает по алгоритму QuickSort/TimSort, сложность которого составляет $O(b \log b)$. Финальный обрез строки занимает $O(n)$. Так как база (максимум 16) превалирует, общая сложность определяется сортировкой алфавита.
   
4. **`countPossibleSecrets` — Временная сложность: $O(1)$ (амортизированная с кэшем) / $O(n)$ (при первом вызове)**
   * *Обоснование:* Без мемоизации рекурсивная функция делает ровно $n$ шагов в глубь (где $n$ — длина числа `length`), уменьшая параметры на единицу до базового случая `length === 0`, что даёт линейное время $O(n)$. Однако, благодаря мемоизации, при повторных вызовах функция мгновенно находит результат в объекте `cache` по ключу за константное время $O(1)$.

## 3. Принципы чистого кода (Clean Code)

* **Принцип единственной ответственности (Single Responsibility Principle):** Каждая функция решает строго одну задачу. `createDigitValidator` только настраивает алфавит, `evaluateGuess` только считает быков, а `ui.ts` занимается исключительно генерацией разметки.
* **KISS (Keep It Simple, Stupid) и Отказ от избыточного кода:** В функции `evaluateGuess` мы отказались от лишнего предварительного условия проверки полного совпадения строк `if (s === g)`, так как базовый метод `.reduce()` сам по себе математически верно обрабатывает эту ситуацию, возвращая массив быков.
* **Иммутабельность данных (Immutability):** Все обновления состояний происходят без мутаций исходных объектов. Массив истории ходов `gameHistory` обновляется строго через spread-оператор копирования (`gameHistory = [...gameHistory, newEntry]`), что полностью исключает использование запрещённого метода `.push()`.
* **Чистый DOM без innerHTML:** Очистка экрана и селекторов от старых опций реализована через легальные и безопасные методы веб-стандартов: в цикле `while (app.firstChild)` с вызовом `app.removeChild()`.
