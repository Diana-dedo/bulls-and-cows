# Архитектурное описание проекта "Быки и Коровы"

## 1. Функциональное программирование и Чистые функции
Вся бизнес-логика игры вынесена в изолированные чистые функции в файле `game.ts`. Функции не имеют побочных эффектов, не мутируют глобальное состояние и не работают с DOM напрямую, что делает их на 100% тестируемыми.

* **Фабрика валидаторов (`createDigitValidator`):** Реализует паттерн "Фабрика функций" и каррирование. Возвращает кастомизированную функцию для проверки символов на основе выбранной системы счисления.
* **Иммутабельный подсчет (`evaluateGuess`):** Рассчитывает быков и коров за один проход с помощью метода массива `.reduce()` без использования императивных циклов `for`.
* **Рекурсивный расчет вариантов (`countPossibleSecrets`):** Использует рекурсию для математического расчета перестановок и оптимизирован с помощью мемоизации (кэширования результатов в объекте `cache`).

## 2. Управление состоянием (State Management)
Состояние игры описывается строгими интерфейсами TypeScript (`GameState`, `HistoryEntry`). Обновление истории ходов и статуса раунда происходит строго иммутабельно с использованием spread-оператора (`[...gameHistory, newEntry]`), что предотвращает непредсказуемые мутации данных.

## 3. Автоматизация и качество кода
* **Тестирование (Vitest):** Все ключевые функции ядра покрыты модульными тестами (юнит-тестами) по методологии TDD.
* **Линтинг и форматирование (ESLint, Prettier):** Код автоматически проверяется и форматируется под стандарт 4 пробелов.
* **Хуки Git (Husky, lint-staged):** Перехватывают коммиты и запускают проверку кода перед фиксацией в Git, гарантируя чистоту репозитория.
